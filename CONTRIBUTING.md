# Contributing to COMB

Issues and pull requests are welcome. Describe the problem, explain the change,
and include relevant validation. For implementation context and checks, see
the README and `system/readme.md`.

Unless explicitly agreed otherwise, contributions to the project's original
code are submitted under AGPL-3.0-only, the same license as the project. You
retain your copyright. Only submit material you have the right to contribute;
obtain employer or other rights-holder permission where required. Identify
third-party material and preserve its license and copyright notices. Do not
include credentials, private keys, or customer repository data.

This contribution policy does not assign copyright or grant a separate right
to relicense contributions under proprietary terms.

Run checks relevant to your change. The README documents the complete Rust,
GUI, installer, and integration checks; `make test` runs the core test gates.
